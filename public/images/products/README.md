# 상품 이미지 폴더

사용 권한을 확인한 상품 이미지만 여기에 넣어요.

- 파일 이름: 상품 ID 그대로 (예: `P021.jpg`, `P031.webp`)
- 넣은 뒤 `data/products.json`의 해당 상품 `imageUrl`에 `/images/products/P021.jpg`처럼 적어요.
- 권한 근거(메일, 약관 캡처 등)는 상품의 `source.note`에 한 줄로 남겨요.
- 외부 주소(https://…)를 써도 되지만, 브랜드 사이트 이미지를 허락 없이 직접 링크하면 안 돼요.

`npm run check:data`로 경로와 파일이 맞는지 확인할 수 있어요.
